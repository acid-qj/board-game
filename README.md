# 棋类游戏大全

这是从原 C++ 五子棋项目扩展而来的网页棋类游戏平台。目前包含五子棋和国际跳棋；PentaZen 已编译为 WebAssembly，会直接在每位玩家的浏览器中思考，不再需要公共 AI 服务器。

在线地址：<https://acid-qj.github.io/board-game/>

## 启动

在本文件所在文件夹运行任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

再在浏览器打开 <http://localhost:8000>。

## 部署

如需在修改 PentaZen 后重新生成浏览器文件，请先安装 Emscripten，再运行：

```bash
./tools/build_pentazen_wasm.sh
```

## 已完成的功能

- 重新开始：首次打开、对局进行中和对局结束后都可用；清空棋盘、保留比分，并交换双方的黑白棋。
- 悔棋：会撤回玩家与 AI 的上一回合，并把剩余棋局重新同步给 AI。
- 投降：确认后 AI 得 1 分，并自动开始新的一局；双方会像 C++ 版一样轮换黑白棋。
- 记分：玩家和 AI 的比分会在当前游戏过程中保留。
- 游戏界面：沿用 C++ 版的棋盘、棋子、棋罐、当前落子者边框和操作图标，并在轮换后同步棋罐颜色与边框位置。
- 移动端：手机竖屏会缩放棋盘并紧凑排列比分与操作区，横屏则使用棋盘和信息栏并排布局；登录、历史棋局和复盘窗口也会适配屏幕宽度与安全区域。
- 对局设置：支持双人模式，以及单人简单（10ms）、普通（50ms）、困难（100ms）三档 AI 思考时间。
- 开始流程：背景首页点击底部“开始游戏”，竹林背景上的竹帘展开一次后显示五子棋入口；点击入口后，竹帘和五子棋入口作为不可点击的底层背景，单双人与难度选项在画面正中央弹出。
- 主菜单：模式选项区域的右下角和棋局页右下角都有小房子按钮，可立即返回已展开的竹帘游戏选择页。
- 在线账号：支持只填写用户名和密码的注册、登录与退出；所有模式开始前都需要登录，以便保存棋局和战绩。
- 在线房间：登录后可以创建 6 位房间号或输入房间号加入，双方棋盘、回合、胜负和投降结果通过 Supabase 实时同步。
- 棋局记录：所有模式开始前均需登录；AI 与在线对局结束后保存胜负及完整落子顺序，可以在账号中的“历史棋局”逐步复盘。同屏双人不保存。
- 历史战绩：AI 及每位在线对手分别统计累计胜负，当前棋局结束后自动更新；同屏双人只保留当前比分，不记录历史战绩。
- 国际跳棋：游戏目录新增独立入口和单双人选择弹窗；当前可进行同屏双人对局，支持 10×10 棋盘、强制吃子、最多吃子优先、兵向后吃子、王棋长距离移动与连续吃子。
- 国际跳棋操作：支持当前比分、悔棋、投降、重新开始和交换双方执子颜色，并完整适配电脑与手机浏览器。
- 国际跳棋 AI：单人模式入口已经预留并明确标记为尚未接入；取得 AI 代码后可继续连接，不影响现有五子棋 AI。

## Supabase

在线账号和房间的数据结构位于 `supabase/schema.sql`，历史记录扩展位于 `supabase/002_game_history.sql`。新建 Supabase 项目后，需要关闭邮箱确认，并按顺序在 SQL Editor 中完整执行这两个文件。前端只使用可公开的 Publishable Key；不要把 Secret Key、`service_role` Key 或数据库密码写入仓库。
