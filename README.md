# 五子棋网页版本

这是从原 C++ 五子棋项目整理出的网页人机对战版本。它会使用同一个 PentaZen AI 程序，网页不需要安装额外依赖。

## 启动

在本文件所在文件夹运行：

```bash
node backend/server.js
```

再在浏览器打开 <http://localhost:3000>。

## 部署

项目已包含 Docker 和 Render 配置。完整步骤见 [DEPLOY.md](DEPLOY.md)。部署时会从 `PentaZen/src` 自动编译 Linux 版本的 AI，旧的 macOS 可执行文件不会上传。

## 已完成的本轮功能

- 重新开始：首次打开、对局进行中和对局结束后都可用；清空棋盘、保留比分，并交换双方的黑白棋。
- 悔棋：会撤回玩家与 AI 的上一回合，并把剩余棋局重新同步给 AI。
- 投降：确认后 AI 得 1 分，并自动开始新的一局；双方会像 C++ 版一样轮换黑白棋。
- 记分：玩家和 AI 的比分会在当前浏览器标签页内保留，包括刷新页面后。
- 游戏界面：沿用 C++ 版的棋盘、棋子、棋罐、当前落子者边框和操作图标，并在轮换后同步棋罐颜色与边框位置。
- 对局设置：支持双人模式，以及单人简单（10ms）、普通（50ms）、困难（100ms）三档 AI 思考时间。
- 开始流程：背景首页点击底部“开始游戏”，竹林背景上的竹帘展开一次后显示五子棋入口；点击入口后，竹帘和五子棋入口作为不可点击的底层背景，单双人与难度选项在画面正中央弹出。
- 主菜单：模式选项区域的右下角和棋局页右下角都有小房子按钮，可立即返回已展开的竹帘游戏选择页。

## 坐标约定

- 棋盘左上角交叉点是 `(0, 0)`。
- 向右移动时 `x` 增大，向下移动时 `y` 增大。
- 前端、后端、落子历史和日志统一使用 `x, y, player`。
- 二维棋盘数组统一使用 `board[y][x]`。
- PentaZen 的坐标输入和输出都使用 `y,x` 顺序：普通回合发送 `TURN y,x`，恢复棋盘时按真实落子顺序发送 `y,x,player`。
